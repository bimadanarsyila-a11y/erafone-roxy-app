Simpan ID Spreadsheet Utama

Perhatikan URL di browser Anda. Salin ID Spreadsheet (kumpulan kode unik acak di antara /d/ dan /edit). Simpan di catatan Anda karena akan digunakan untuk pendaftaran.

4

Salin Link Rekap & Summary Report

Agar dashboard bisa membaca data toko Anda, Anda wajib menyalin 2 URL link dari tab/sheet yang spesifik:

A. Link Rekap Report (Untuk Data ERO)

  • Klik sheet/tab Rekap report di bagian bawah spreadsheet.
  • Copy/Salin seluruh URL link di bagian atas browser Anda.

B. Link Summary Report (Untuk Dashboard Sales)

  • Klik sheet/tab Summary report di bagian bawah spreadsheet.
  • Copy/Salin seluruh URL link di bagian atas browser Anda.
